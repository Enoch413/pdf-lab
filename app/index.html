1. 반 선택

Firebase에서 내 반 목록을 불러오면 반별 출제와 CHECK 세트 반 ID가 자동으로 연결됩니다.

CODE LAB에서 쓰는 Google 관리자 계정으로 로그인하면 로컬에서도 반/학생 목록을 불러옵니다.

4. 지문 선택

5. 유형 선택과 draft 생성

선택한 지문들에 존재하는 유형이 여기에 표시됩니다. 기본값은 전체 선택입니다.

6. 생성 결과

아직 생성된 draft가 없습니다

반 선택, 지문 선택, 유형 선택을 마치고 draft 생성 버튼을 누르면 결과가 여기에 표시됩니다.

생성 결과에서 틀린 정답이나 해설만 골라서 수정하면, 현재 draft와 공용 라이브러리 원본이 함께 갱신됩니다.

7. 오답유형 다시 풀기

1차 공통 세트를 시작하면 선택한 반의 학생이 자동으로 연결되고, 학생별 오답 유형만 같은 지문/유형의 다른 문제로 다시 낼 수 있습니다.

오답 재출제 세트가 없습니다

먼저 각 지문별 유형당 1문제 draft를 만들고, 현재 draft를 1차 공통으로 시작하세요.

학생별 출력 이력

학생별 오답 재출제 출력은 반 공통 출제 이력과 분리되어, 공통 시험의 이전 출제 제외 규칙에 섞이지 않습니다.

저장된 학생별 출력 이력이 없습니다

오답 재출제 draft에서 출제 이력 저장 + PDF 출력을 누르면 현재 학생 기준 출력 이력이 여기에 쌓입니다.
